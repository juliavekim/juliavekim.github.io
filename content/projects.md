## Course projects

### Using a Deep Deterministic Gradient Policy (DDPG) to Control a Two-Joint Arm

Mar.–Apr. 2023  

University of Toronto · Machine learning course project

- Implemented DDPG reinforcement learning in MATLAB to optimise a two-joint robotic arm.
- Developed and trained neural networks with ReLU activation, stochastic gradient descent, and Adam optimisation.
- Improved policy returns over 1,000 rollouts using test policies and minibatch learning with a replay buffer.

### Learning MNIST Handwritten Digits with a Retinotopic Map

Feb.–Mar. 2023  

University of Toronto · Machine learning course project

- Implemented digit recognition using backpropagation with Adam and Nesterov in MATLAB.
- Developed a three-layer mapnet with ReLU activations, softmax classification, and minibatch learning.
- Reduced classification error from 480 to below 170 incorrect guesses over 10 epochs, across 60,000 training and 10,000 test examples.
